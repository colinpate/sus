# Reports

This directory is the human-readable conclusions layer:

- `front_mag_nuisance/`: consolidated body/world magnetic-nuisance investigation,
  including the current algorithm comparison, error budget, and archived sweeps.
- top-level `rear_*` folders: narrative experiment reports generated by focused analysis scripts.
- `slayer_*`: import, dropout, and independent-chunk diagnostics for the Slayer recordings.

Compact, reproducible experiment records belong under `experiments/`. The four
older direct-aggregator bundles still cited by rear reports are preserved under
`experiments/legacy_stats/`; the superseded bulk `reports/stats_aggregator/`
output has been retired.

For front magnetic-field correction, start with
`front_mag_nuisance/README.md`; it distinguishes current magnitude-era results
from older projection-era and encoder-supervised diagnostics.

## Current Rear Summaries

These are the best entry points for the current rear pipeline work:

- `rear_accel_filtering_148_154/`: final summary for the 4 Hz rear accel HPF change.
- `rear_zv_accel_correction_148_154/`: summary for the mag-ZV acceleration correction work.
- `rear_chunking_tradeoffs_148_153/`: chunking/training tradeoff analysis that explains the low-travel versus high-travel behavior.

## Supporting Sweep Artifacts

These are useful when you need detailed tables behind a summary, but they are not the first stop:

- `rear_accel_filtering_148_154_exact/`: broad uncapped HPF/filter sweep.
- `rear_accel_filtering_148_154_screen/`: chunk-capped screening sweep; superseded for final decisions by the exact/solver runs.
- `rear_accel_filtering_148_154_solver/`: focused solver-evaluated HPF comparison.
- `rear_zv_accel_correction_exact_148_154/`: uncapped ZV correction sweep.
- `rear_zv_accel_correction_screen_148_154/`: chunk-capped ZV correction screen; useful as a control, but not the final metric source.
